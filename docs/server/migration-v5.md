# 账号库与 v5 备份迁移

匿名 `408-user` 保持 v4；每个账号独立使用 `408-user:<uuid>` v5 和 `408-content:<uuid>` v3。账号数据库增加 outbox、syncHeads、syncConflicts、syncMeta；内容库增加缓存元数据，跨账号字节预算由独立 registry 统计。没有修改真实用户数据文件。

首次登录不会自动归入旧记录。在数据管理里预览旧库、下载带摘要恢复材料，再选择归入当前账号。原匿名库不删除。v1–v3 的重复笔记先保存全部原文，v4 的笔记冲突档案继续保留。

如已有账号命名的 v4 库，先显示快照下载和关闭其他标签页入口，再允许升级；升级事务内再保存一份可校验的 v4 恢复快照。版本升级被阻塞时等待旧连接，旧连接收到版本变更即关闭写入，未保存输入留在页面供复制。注入事务失败后 v4 原文与版本仍可读，不把测试注入等同于真实断电。

v5 备份在同一只读事务内导出学习数据、待同步操作、同步头、冲突和恢复档案，再计算摘要。只允许同账号恢复 v5；导入预检验证摘要、事件可重放、关联完整性及重复键。替换前保存全部本地表快照，恢复后清除旧游标，下一次联网重新对账。不能对未知来源的两份 outbox 自动合并。

合法 v1–v4 备份可显式合并或恢复到账号本地库。旧匿名每日计划保留在原始导入档案里，不覆盖服务器清单；导入轮次的匿名计划关联解除，练习/评分原文和时间保留。替换仅作用于本机视图，服务器原始作答不会被删除；后续同步会恢复服务器已有记录或保留差异为冲突，不能把恢复旧备份当成撤回服务器学习历史。

笔记和个人卡冲突显示双方内容，显式合并后生成新的版本校验操作。练习/卡片轮次冲突可保留本机过程为独立轮次，原始证据保存在档案中；模考冲突不改写为普通练习，先导出双方原文。所有未解决事务及其依赖停止自动重试。

备份包含：作答、会话、提示与首答证据、笔记、错因、收藏、个人卡、复习评分、每日计划、模考、同步队列、冲突和恢复档案。**不包含**共享/本地 PDF、题包、图片缓存、登录密码、Cookie 和服务器密钥。旧应用不能读取 v5，恢复升级前快照也不含升级后的记录。

离线继续学习资格为最后一次成功认证后的 7 天；退出会保留账号数据并锁定，未送达服务器的退出在下次在线登录前先撤销。在线已知的会话失效会清除离线凭据。另一标签页切换账号时锁定旧页，写请求携带预期账号，服务端拒绝Cookie已切换后的旧账号请求。

退出意图先同步保存在不含凭据的本地标志中，再异步记录到账号registry，避免点击后立刻刷新恢复旧会话。待撤销请求失败时继续锁定，不允许直接切换账号。两台设备对同一题新建不同ID笔记，或对同一卡建立不同个人副本时，拉取先保留冲突双方，不向当前列表插入重复逻辑记录；解决冲突前仍能导出完整v5备份。
