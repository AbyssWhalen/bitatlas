## 20 篇原创短讲解检查

以下为本轮代理逐篇检查记录，不能记作人工审核。每篇包含解释、自编例题、常见错误、有效题目与卡片链接、来源定位；来源证明概念定位，不冒充原卷包含自编例子。正文保持 `ai-assisted` / `needs-review`。每科 5 篇，优先按历年覆盖与题量选择。
