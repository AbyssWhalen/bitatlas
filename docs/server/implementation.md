# 邀请制服务器版实施合同

批准日期：2026-11-20。本轮本地实施与验收；真实服务器、密钥、CI、DNS、远端上传、永久删除和发布另行授权。

## 已锁定的选择

- GCP 单机，Node 24 / Fastify 5 / better-sqlite3，SQLite WAL 与私有文件目录。
- 全站邀请制，管理员/成员两角色；管理员上传并发布的资料成员默认共享，学习记录始终私有。
- 保留缓存题目/卡片离线学习；未退出账号离线资格 7 天。PDF 主动下载才离线保存，单份 128MiB。
- 可再下载缓存默认 250,000,000 bytes，跨账号合计；不淘汰未同步记录、唯一副本或固定离线资料。
- 原 799 题/80 卡为首批，新增 20 篇概念讲解；不把网盘目录当正文，不导入整包视频，不提升人工审核状态。
- 题目缺核心内容/答案时暂停练习，只缺解析时局部标明。旧记录、ID、版本引用保留；既有正式模考门槛保持。
- 账号内容库 v3、用户库 v5、备份 v5；原匿名库只作为显式迁移来源，合法 v1–v4 备份继续接受。
- 同事务 outbox、按用户幂等操作、epoch/sequence 增量游标；笔记/个人卡/同轮并发冲突保存双方。
- 北京日期的每日安排由服务器固定；离线无当天安排时可加练，不制造不同设备的多个今日清单。
- 北京腾讯云仅为加密备份目标。age + SSH，7 日/4 周快照；证据独立归档，永久删除仅生成候选清单。

## 阶段与验收

1. 内容可用性、跨年筛选和界面；生成真实答案对照覆盖报告；20 篇短讲解与有效来源。
2. 服务端基础、邀请/撤销、资料预检/发布、4MiB 分块上传、鉴权 Range 阅读。
3. 账号隔离、离线同步、固定计划、旧数据显式迁移、备份 v5 与故障恢复。
4. 桌面/手机 E2E、PWA 更新、全仓门禁、20 用户 30 分钟混合负载、5 路 PDF、备份恢复与部署包。

新增 API 使用 `/api/v1`；前端通过仓储访问。认证使用服务器可撤销的随机会话与 HttpOnly Cookie，写请求校验 Origin；scrypt、有限登录尝试和有限密码校验并发。正式包仅公开应用壳，不打包私人题面。

验收必须报告实际测试数/workers/失败和资源；原 234 E2E 覆盖不以删用例方式减少，8 workers 压力单列。本机约 1GB 是远端归档后的常驻目标，测试临时峰值另计。旧 5.13GiB 历史证据保留。
