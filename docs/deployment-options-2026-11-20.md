# BitAtlas 大陆服务器与域名部署选项

核验日期：2026-11-20（北京时间）。本次为部署咨询与公开资料核验，尚未选择或执行迁移路线。

## 结论与建议

- 用户补充：`fytjut.com` 已挂有多项服务，担心停站、费用和办理时间。因此调整建议为：暂不迁动该主域名；若确认需要大陆公开主站，优先使用另一个独立域名备案。若继续个人使用且无紧迫的大陆公开服务需求，可保持当前境外托管并让大陆机器承担非公开任务。这是建议更新，用户尚未选定路线。
- 高信心：境外注册的域名不是永远不能用在大陆。当前需解决的是注册商资质、域名实名、ICP备案及实际接入关系；DNS 能解析不代表已满足大陆网站开通条件。[1][2][3]
- 高信心：现有 `fytjut.com` 仍可作为保留访问地址路线的候选，转入合资格境内注册商、实名后申请备案。备案使用主域名，`408.fytjut.com` 作为其子域名使用；新建另一个子域名不能隔离主域名转移和备案的影响。[1]
- 中等信心的部署建议：若目标是长期向大陆用户开放，优先评估腾讯云 4 核 4 GB / 5 Mbps 作为主站，华为云 2 核 2 GB / 2 Mbps 作为非公开备份或辅助任务资源。选择依据是用户提供的配置与当前静态应用架构，未做服务器性能测试。
- 架构建议：先完成静态托管迁移与资料按需分发，继续保留本地学习记录。云端资料管理和跨设备同步分别立项，不把“换服务器”当作已经获得云同步。

## 续费归属与备案后的服务范围（补充核验）

- 用户进一步表达希望长期持有备案域名，同时重视现有注册渠道的低价和其他服务的连续性。因此推荐另选续费可接受的独立主域名备案，现有主域名先保留原注册关系；尚未执行任何域名或账户变更。
- Squarespace 官方明确：域名转出后，账单和域名管理由新注册商负责，原有优惠不构成新注册商的续费报价。不能将“转入境内注册商”和“继续通过原 Google / Squarespace 渠道续费”作为同时成立的方案。[16]
- 经 Google Workspace 购买的 Squarespace 域名可能由 Google 作为经销商负责账单和续费，Squarespace 为注册商；取消 Workspace 套餐不自动取消域名订阅。域名详情中的 `Reseller: Google` 可帮助确认当前关系。未读取用户的账户账单、续费报价或合同，不确认其以后能持续获得相同低价，不记录特殊地区购买细节。[17]
- “先转入备案、再转回未获批的境外注册商”不是稳定的保留备案方案。华为云明确将备案后转至未获工信部批复注册商列为核查不合格原因，并要求转回合资格注册商或取消接入/注销。这不等于断言转出当日自动注销。[18]
- 费用参考：本次检索到腾讯云公开标准价格表列普通 `.cn` 续费为38元/年，动态结算订单未核验，特殊域名及未来调价不适用此保证。腾讯云另有2026-11-01生效的 `.com` 调价公告，因此不把搜索缓存中的 `.com` 旧价格作为当前报价。比较长期持有成本应查看续费价，而非只看首年活动价。[19][20]
- 备案后网站内容仍需与备案主体和申报性质相符；备案信息、注册商、实际接入和服务内容会被持续核查。备案不是任意内容或电信经营活动的许可。[18][21]
- 对管理面板需按实际用途判断：服务器自用管理、反向代理管理，与对外销售或运营跨境代理服务不是同一种服务。工信部对相关VPN政策的官方解释重点针对未经许可开展跨境电信业务经营；不能据此断言所有自用代理都违法，也不能反向保证自用代理一定合规。判断具体服务需要访问范围、部署地点和实际业务信息，本次未审计任何面板或代理服务。[22]
- 同主域名下分开子域名不提供完全风险隔离。《互联网域名管理办法》第四十条允许依法对违规域名停止解析；据此可推断，如果处置作用于整个主域名，其他子域名也可能受影响，但不是任何一个子域名被认定有问题就必然整域封停。[23]
- 新域名建议用于BitAtlas及明确允许的正式内容；管理后台按最小公开范围规划。分开域名是服务和故障范围的隔离建议，不能改变业务本身的合法性或使未备案大陆公开服务获得豁免。

## 三条可选路线

| 路线 | 适用情况 | 主要事项 |
| --- | --- | --- |
| 保留域名，转入境内注册商并备案 | 希望保留现有访问地址、长期使用大陆服务器 | 转移整个 `fytjut.com` 的注册管理，实名，通过腾讯云申请备案，完成后再切换公开主站 |
| 另用已实名的境内注册域名申请备案 | 不希望调整 `fytjut.com` 的注册管理或关联站点 | 原域名保留原有托管；新站会形成新的浏览器 origin，需要导出/导入学习数据，PDF 另行处理 |
| 保留境外托管，或另选香港/境外服务器 | 暂不打算办理大陆ICP备案 | 公开服务留在相应地域；现有大陆机器可用于非公开文件备份或内部任务，不作为未备案公网网站的源站 |

香港及其他境外地域的网站不需要中国大陆 ICP 备案；采用该路线需要准备相应地域的托管资源，用户现有大陆实例不等同于香港或境外实例。[5]

域名转入腾讯云时可选择仅转移注册管理并保留原 DNS；转移的是整个主域名，不是单独转移 `408` 子域名。先盘点主域名的其他站点、邮箱、DNSSEC 等配置。官方说明境外域名转入期间可能因实名核验暂停解析，因此不能保证绝对无停机。转入通常包含增加一年有效期的费用，价格以实际订单为准，本次未报价。[4]

## 多服务域名的停站、费用与时间

### 两种不同的服务中断风险

1. 首次备案期间，腾讯云要求未备案网站在备案成功前不能开启访问、不能做解析。不能把已备案域名的新增接入流程中可能允许不停站，套用到首次备案。[11]
2. 转移注册商时，保留原 DNS 通常能维持解析，但腾讯云明确提醒：从非大陆注册商转入中国站，域名可能因实名限制被 `serverHold`，导致域名无法访问。这是域名级风险，不能保证同主域名的其他站点或邮箱不会受影响；也不能断言所有转入一定停机。[4]

本次未核验用户的全部子域名、服务部署地或备案主体所在地，不能承诺“只停408，其他子域名全不受影响”，也没有证据认定其他服务必须全部停满整个办理周期。若仍选择原域名，先拿实际服务清单向接入商预审确认关闭范围及转入安排，再执行变更。

### 费用

普通自助 ICP 备案基础服务可以免费办理，华为云和阿里云官方均明确提供免费基础备案；付费备案管家属于另外的增值服务。[12][13]

实际预算来自域名与服务器：原域名转入腾讯云需要续费一年；新域名有注册和后续续费费用；服务器若不满足备案资格，可能需续期或调整产品。以上不是政府收取的备案费，本次没有查询或承诺具体域名价格。[4][6]

### 时间预算

| 环节 | 当前官方说明 |
| --- | --- |
| 境外域名转入腾讯云 | 一般 3–7 个工作日，取决于注册局处理。[4] |
| 域名实名信息同步 | 实名完成后建议至少等待约 3 天再申请备案；这不包含实名审核本身所需时间。[1] |
| 腾讯云初审 | 约 1–2 个工作日。[11] |
| 省管局审核 | 腾讯云说明的一般办理口径为 20 个工作日以内，周末及法定节假日不计；但同页省份参考表含更长区间，因此不保证实际总历时。[11] |

对“先转境外域名再首次备案”的路线，建议安排约 4–6 周的计划窗口。这是预留时间，不是官方总时限或实际交付保证；补正、审核退回等会使总历时增加。官方FAQ同页的江苏参考值为9–30工作日、云南为16–21工作日，与其概述的20工作日口径并不完全一致，应按实际备案省份进一步确认。新域名路线可省掉原主域名的转移环节，也无需为新域名申请而更改原主域名的注册或DNS配置。

Squarespace 转出说明另外提示完整转移过程可能长达15天，因此不能把腾讯云的3–7工作日一般值当作此域名的确定承诺。[16]

### 不备案时大陆服务器可以怎样使用

- 面向公众的网站仍放在境外托管；大陆机器用于非公开备份、构建或内部数据处理。
- 若只供本人或受控用户使用，可另行设计非公开部署及受控私有网络访问，必要时用内部 DNS 保持熟悉的域名名称。华为云官方说明私有域名仅在关联 VPC 生效，无需公网域名备案；用户电脑到该网络的连接、HTTPS及访问控制仍需单独设计，不能把 VPC DNS 直接当作公网方案。[14]
- 对“任何人从公网打开现域名、由大陆机器提供网站服务”的目标，仍按大陆网站备案要求处理。境外代理或隧道改变流量路径，不能据此推断获得备案豁免，也不把境外页面搭配未备案大陆公网 API 当作免备案方案。[15]

## 备案与服务器条件

- 腾讯云 CVM / Lighthouse 当前要求中国大陆地域、包年包月、购买累计不少于 3 个月（含续费），备案期间剩余有效期不少于 1 个月，并满足公网 IP、带宽等条件。具体资源是否可选需看用户控制台，CPU 与内存大小不能证明备案资格。[6]
- 华为云同样要求符合条件的大陆资源；官方当前服务器准备说明对 ECS / Flexus 相关实例列出包年包月、至少 3 个月及备案次数限制。本次没有核实用户华为实例的产品类型和资格。[7]
- 网站备案通过后，还需按要求展示备案号、办理公安联网备案等上线事项。腾讯云当前指引要求网站开通后 30 个自然日内提交公安联网备案申请。[3]
- 个人备案的主体信息、域名实名和服务内容需符合所在地规则；应如实描述为实际提供的个人学习工具，不能通过更换名称掩盖收费培训等不同业务。[1][8]
- 已在一个接入商备案，后续换到另一家大陆接入商，通常还需办理新增接入；同时使用多家厂商提供网站服务，可以保留多个接入关系。不要把“腾讯备案一次”理解为自动完成华为接入。[9]
- 直接 IP、改端口或加境外代理不能作为未备案大陆公网网站的正式上线路线；腾讯云明确指出通过域名或仅通过 IP 提供网站服务均需履行相应备案手续。[3]

## 项目实际的数据边界

以下来自本次读取的 [README](../README.md) 和 [架构文档](ARCHITECTURE.md)，不是对服务器容量的推测：

- React / Vite / PWA 应用目前无需服务端 API 即可运行，题包、学习包与来源图片可以由静态服务器分发。
- `408-content` v2、`408-user` v4 在浏览器 IndexedDB。
- 用户导入的本地 PDF 字节保存在浏览器 Cache Storage，不因更换网站服务器而自动上传。
- v4 学习备份不包含本地 PDF 字节。迁移前应导出学习备份，并单独保留 PDF 原件；说明见 [迁移合同](learning/migration-v4.md)。
- 保留相同 HTTPS 域名及端口只是更换托管，浏览器 origin 不变；更换域名则不能直接读取旧域名 IndexedDB。仍需验证 PWA 更新、缓存和数据恢复，不能只以网页打开成功验收迁移。[10]
- 云端文件上传、访问权限、跨设备记录同步、冲突处理与服务端备份属于新增能力，需要独立设计，不能靠 Nginx 静态托管自动获得。

按用户给出的出口上限换算，未扣协议开销：

| 服务器 | 理论总出口字节速率 |
| --- | --- |
| 华为云 2 Mbps | 约 0.25 MB/s |
| 腾讯云 5 Mbps | 约 0.625 MB/s |

以上是 `Mbps ÷ 8` 的十进制换算，不是实测速度，且多用户共享总出口。更多资料首先取决于可用磁盘/对象存储容量，下载体验还受带宽、并发和缓存影响。建议按需获取图片/PDF，不在首页一次性下载所有资料。

## 下一步需要的信息与实施边界

路线选择后，先核对腾讯实例的地域、产品类型（CVM / Lighthouse）、操作系统、购买与剩余时长、磁盘余量及已有服务；再核对主域名关联站点与备案主体所在地。无需在聊天或仓库提供密码、转移码、身份证信息或云 API 密钥。

实际实施应另有经确认的部署计划：备份与回滚、HTTPS 和深链接、受控发布目录、PWA 双版本升级、同域学习数据恢复、内容访问范围。只有经确认可发布的站点与内容进入 Web 目录；本地 PDF、来源原件、`local-data/`、`output/` 和测试历史不随整仓上传。

本次没有登录服务器或云控制台，没有修改 DNS / 域名账户 / CI / 密钥 / 数据库 / 产品源码，没有部署、购买或重新执行已完成的清理和测试。
