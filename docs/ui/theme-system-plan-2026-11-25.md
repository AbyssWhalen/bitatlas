# 可切换主题方案（2026-11-25，组长）

维护者确定：BitAtlas 默认保留现在的“经典”界面，另外提供可切换主题，首个主题是“朱墨算经”（样张见 `output/design-directions-2026-11-25/editorial-almanac/`）。样张里那些有特色的互动，不管选哪个主题都要做。

## 结构

主题分两层，都不改学习逻辑与数据：

| 层 | 怎么实现 | 举例 |
|---|---|---|
| 外观层：随主题切换 | 根元素新增 `data-skin`（`classic`、`almanac`，之后可加）。每个主题一份样式文件，只覆盖语义令牌，例如颜色、字体、纹理、边框、圆角、阴影；与现有昼夜 `data-theme` 正交，所以每个主题都有白天和夜间两版。 | 宣纸底和朱砂色、宋体标题、骑缝虚线 |
| 主题签名组件：少量、按主题渲染 | 少数位置读取当前主题，渲染该主题的专属装饰；其他主题用默认渲染。数量控制在 5 处以内，避免每页维护多套布局。 | 朱墨主题的竖排页眉、超大朱砂数字、四科书脊 |
| 互动功能：所有主题共有 | 做成共享组件，外观跟随主题的令牌。 | 见下表 |

## 共有的互动功能（来自样张，经典主题同样上线）

1. 完成今日一项时的完成动效：朱墨主题是撕签加盖朱印，经典主题是键帽按下加印记。
2. 概念状态升级时的“点亮”过程，概念寄存器、知识页都有。
3. 本周学习节奏：七天印记，点击可查看当天记录。
4. 答错后的批注式反馈：在原有闭环卡上加醒目的“订正”标题和误选原因，朱墨主题用朱笔样式。
5. 音效：默认关闭，在设置里打开，尊重系统的“减少动画”设置。
6. 键盘：今日页按空格推进下一项。

## 设置与存储

- 设置页新增“界面主题”，提供“经典（默认）”和“朱墨算经”两项，顶栏菜单可以快速切换。
- 主题偏好和昼夜偏好一样，只存在浏览器 `localStorage`，属于界面偏好，不算学习数据，也不进同步和备份。首帧脚本（`index.html`）同时读取这两项，避免切换时闪烁。
- 字体自托管，使用 OFL 等开源许可的字体，并做子集化控制体积。只在选中对应主题时加载，经典主题不多下载。

## 分块实施（每块单独交付，组长审核后再做下一块）

1. **主题基础**：`data-skin` 机制、首帧脚本、设置项、朱墨主题的令牌与字体。全站切到朱墨后颜色、字体、纹理生效，经典默认不变。
2. **今日页**：朱墨签名组件（竖排页眉、大数字、书脊寄存器），以及共有的完成动效、本周节奏、空格推进。
3. **练习与复习**：批注式判错反馈、概念点亮、记忆卡评分手感。
4. **知识页与其余页面**：主题细节补齐；实验页画布保持深色仪器风格，外框跟随主题。
5. **可选**：再加主题，例如琥珀示波台、深紫外晶圆，由维护者决定。

## 验证（相称即可）

- 每块：相关单测、lint、typecheck，加真实浏览器两种主题 × 昼夜 × 1440/390 截图目检。
- 部署前：完整门禁跑一次。
- 不做像素级比对。经典主题的外观应保持不变，抽查几个页面即可。
