## 1. 风格边界：三层分区

| 区域 | 页面 | 允许的视觉手法 |
|---|---|---|
| 外壳层 | 顶部导航、今日首页、知识总览、登录 | 键帽按钮、3px 粗边、硬投影、得意黑大标题、亮绿状态色 |
| 阅读层 | 练习、记忆卡、讲解、解析、PDF | 1px 细边，**不用**硬投影、倾斜、大面积亮绿；正文 18px，行宽约 68 字；颜色只用来表示状态 |

- **字号**：最小 13px，正文 `--reading-font-size`（默认 18，可调 16–24）。标题按阶梯放大：28 / 36 / 48；首页主标题用 `clamp(36px, 5vw, 64px)`。
- **字体**：
  - 标题：得意黑，子集化后自托管为 woff2。OFL 带保留字体名，子集文件的内部名改为 `BitAtlas Display`，并附 OFL 原文。
  - 正文：系统中文字体。
  - 数字和代码：JetBrains Mono（OFL）自托管。
  - 不依赖 Google Fonts。
- **动效**：只给按键下沉（60ms）、状态变化（200ms）和登录页的比特阵列加动画；全部尊重系统的"减少动画"设置。

## 3. 寄存器（概念总览）

- 102 个叶概念各对应一格，按科目分四行，科目用形状符号 ▲ ■ ● ◆ 区分，不靠颜色。
- 每格四种状态，全部由学习记录派生，**不显示百分比**：

| 状态 | 判定（具体口径由 Codex 的只读接口定义） | 外观 |
|---|---|---|
| 未开始 | 当前版本下该概念没有有效作答或卡片事件 | 灰格 |
| 练习中 | 有记录，但最近的客观表现不稳定 | 细边框加斜线 |
| 待巩固 | 近期表现良好，但还有到期复习或间隔不足 | 半格点亮 |
| 稳定 | 题目和卡片证据都满足稳定条件 | 全格点亮 |

- 今日任务涉及的概念加一圈红框。**点击格子进入概念详情**（相关真题、卡片、讲解、实验），格子本身不能改状态。
- 键盘操作：每一行只占一个 Tab 停靠点，行内用方向键移动；聚焦和悬停时都更新说明文字。
- 尺寸：桌面每格不小于 24×24px、间距 4px。手机上折叠成四条科目进度，点开再看格子。
- 去掉十六进制读数。
- 首页标题只陈述真实计划，例如"今天 11 项 · 涉及 6 个概念"，**不说"点亮 N 个比特"**。

## 4. 页面清单与要点

1. **外壳**：
   - 桌面用顶部键帽导航（今日 / 题库 / 复习 / 知识 / 实验 / 更多），快捷键只在焦点不在可编辑区域、且不处于输入法组字状态时生效。
   - 手机保留底栏"今日 / 题库 / 复习 / 知识 / 更多"。
   - 字号放进顶栏的"阅读"菜单，一次点击就能打开。
2. **今日**：
   - 主标题加一个主按钮；任务票按顺序展示真实计划项。手机上任务票改成竖向排列，不横向滚动。
   - 寄存器放在右侧，手机上放在任务下方。
3. **练习**：
   - 题干在阅读层。选项是整行按钮，左侧显示 A–D 键位，A–D 快捷键可用。
   - 提交并判错后，显示现有错因枚举（概念 / 方法 / 计算 / 审题 / 其他），可以跳过。
4. **记忆卡**：
   - 在阅读层，先回忆再显示背面，评分用三个键帽（1 / 2 / 3）。
   - 挖空卡暂不实施；以后实施时，未揭示的内容不放进 DOM，揭示按钮带 `aria-expanded`。
5. **知识页**：整页寄存器加概念详情抽屉，复用现有实验链接，不另编实验。
6. **实验**：统一使用展厅布局（标题、控制区、画布、逐步说明），先改外壳，不重写实验逻辑。
7. **其他调整**：
   - 未开放的模考移出主导航，放到"更多"里并注明开放条件；历史记录入口保留。
   - 内容复核移到管理入口，旧地址跳转兼容。
8. **以后再做**：打印版卡片、登录页比特阵列、草稿笔迹，不阻塞上面几项。

## 5. 需要 Codex 提供的只读接口（按优先级）

1. 概念状态：每个叶概念返回 `{ state: 'unstarted'|'practicing'|'consolidating'|'stable', questionCount, attemptedQuestions, cardCount, dueCards, labIds, lastActivityAt }`。口径由 Codex 决定并写进文档；未检测的概念要和 0 区分开。
2. 今日计划与概念的映射：每个计划项对应哪些 `conceptIds`，用于给格子加红框和统计"涉及 N 个概念"。
3. 卡片显示名：用 `conceptIds` 查到的概念名，或者由 front 派生的短标签，替代 `targetId.replace(...)`。
4. 会话和同步状态：模式、登录状态、待同步条数、离线资格到期时间；最近一次成功同步时间没有就返回 `null`，不要编造。
5. 本周学习天数（按北京时间、以周一为一周起点，只统计有效作答和卡片事件）。暂不做连续天数和休整机制。
6. 字体：确认服务器模式下 `publicDir` 关闭时 woff2 能被复制或导入，Workbox 能预缓存。
