## UI 改版需要 Codex 配合的事项

UI 改版计划用"线路图"组织首页和知识页，需要 `app/` 提供以下**只读**数据接口。不改 schema、同步或鉴权；UI 侧只消费这些接口。

1. **概念级进度**：每个叶概念（102 个）的 `{ attempted, correctRate, mastery, lastPracticedAt, questionCount, cardCount, labIds }`，按当前题面版本过滤，与知识页现有口径一致。
2. **学习天数**：按北京时间统计的连续学习天数和本周活跃天数。只做统计，不加任何惩罚逻辑。
3. **会话/同步状态**：当前是本地模式还是服务器模式、登录状态、待同步条数、离线资格剩余天数、最近同步时间。
4. **字体与预缓存**：UI 可能需要自托管一个子集化的中文标题字体（预计不超过 300 KB）。需要在 `vite.config.ts` 的 PWA 预缓存里加入对应路径，具体文件名到时写进 `docs/ui/opus-handoff.md`。
