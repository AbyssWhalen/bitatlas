# BitAtlas 视觉新方向探索报告（2026-11-25 · 破框重塑版）

针对维护者“不能说难看，就是给人一种老套的感觉”的反馈，以及组长对首轮方向一“仍像好看的 SaaS 仪表盘（浅底、通用蓝、圆角两栏卡片）”的审阅意见，本轮彻底破除了 **圆角卡片网格、对称双栏分屏与通用蓝色按钮** 三大模板套路，交付 **3 个远看即处于不同视觉宇宙** 的独立静态可交互样张。

三套样张均位于 `output/design-directions-2026-11-25/`，全部包含 **今日页 + 练习判错复盘 + 知识脉络/实验画布** 三屏、真实 2024 年 408 真题推导、白昼与夜间双主题、键盘全快捷键、**默认关闭但可一键开启体验的 WebAudio 声画同步物理反馈**，并通过 Playwright 实测 `1440px` 与 `390px` 视口下 **0 横向溢出、0 控制台错误、所有可见正文与按钮对比度 ≥ 4.5:1**，尊重系统 `prefers-reduced-motion` 设置。

## 方向一：深紫外硅晶光刻 · `silicon-lithograph`（破框升级版）

### 1. 一句话概念
去掉一切圆角卡片与 SaaS 蓝，整页是一张 **带 45° 斜切角（Chamfered `clip-path`）的钛金属光刻蓝图**：470px 圆形 102 核硅晶圆占据视觉主场，下方横贯全幅六级指令取指流水线，练习判错直接炸开成通栏 38-bit 硬件位段标尺。

### 2. 色板（白昼：钛白深紫外 / 夜间：EUV 光刻暗室）
- **底面与金属板**：白昼 `--titanium: #EBE8E1`、`--plate: #F7F5F0`；夜间 `--titanium: #08060E`、`--plate: #110D1B`。
- **正文与刻度**：白昼 `#120F1A`（对比度 `16.8:1`）/ `#4C445C`（`7.5:1`）；夜间 `#F3EEFA`（`16.4:1`）/ `#B6A8CC`（`8.1:1`）。
- **记忆色**：
  - **EUV 深紫外激光紫**：白昼 `#5A189A`（配白字 `9.4:1`）/ 夜间 `#C985FF`（配深墨 `8.6:1`）；
  - **蚀刻铜互连线**：白昼 `#A33B04` / 夜间 `#FF9B4A`；
  - **氮化硅良率绿**：白昼 `#0A6946` / 夜间 `#3FE39B`。

### 3. 字体方案（可自托管开源字体 + 本机高辨识度后备）
- **巨型坐标与工业标题**：生产自托管推荐 `Chakra Petch` 或 `Barlow Condensed Bold`（SIL OFL 1.1）；样张实配 `Bahnschrift Condensed` / `Stencil`，呈现紧缩硬朗的掩模编号（`PC//03`、`EUV-13.5nm`）。
- **中文阅读正文**：`Source Han Sans SC / 思源黑体 Regular`（SIL OFL 1.1），`18px` 题干长读清爽不刺眼。
- **寄存器与十六进制**：`JetBrains Mono` / `Cascadia Mono`（均为 SIL OFL 1.1）。

### 4. 核心互动清单
1. **470px 巨幅 102 核硅晶圆 + 激光准星锁死 + 跨科铜互连线**：点击任意晶粒即刻弹出铜色双环准星并拉出正交跨科耦合铜线；点击 `光刻升阶选中晶粒 ↗` 现场体验晶粒逐档变色锁相。
2. **通栏指令流水线轨道（`IF / ID / EX / MEM / WB / CMT`）**：按 `Space` 或点选切角指令卡推进 `PC ACTIVE ▶`，左上 `104px` 巨型 `PC//03` 坐标同步跳变。
3. **通栏 38-bit 地址位段拆解标尺（2024 Q17 真题）**：按键盘 `A–D` 切换选项时，通栏标尺实时指出 `B(17位)`“漏除以 4 路”的精确位宽错位。
4. **4 路组相联 CAM 比较器探针 + 默认静音的晶振声画反馈**。

- **路径**：`output/design-directions-2026-11-25/silicon-lithograph/index.html`（同目录附 `day-1440.png`、`night-1440.png`、`day-390.png`、`night-390.png`）

## 方向二：朱墨算经 · `editorial-almanac`（主推荐候选 · 极致人文编辑感）

### 1. 一句话概念
彻底抛弃“软件界面”范式，做成一本 **摊开的宣纸朱墨雕版算学专著**：左侧 `46px` 竖排华文中宋大字眉题，中央 `112px` 朱砂斜体巨型数字与虚线骑缝撕票签，右侧立起四册竖排藏书脊，底部以 `100vw` 满幅乌金泥金长卷展开操作系统河图脉络。

### 2. 色板（白昼：宣纸松烟朱砂 / 夜间：乌金大漆泥金）
- **纸张与漆底**：白昼宣纸 `--paper: #F5EDE0`、`#FBF7F0`；夜间乌金漆底 `--paper: #120E0C`、`#1C1613`。
- **正文墨色**：白昼松烟墨 `#17120E`（对比度 `15.8:1`）；夜间暖象牙白 `#F3EAE0`（对比度 `15.2:1`）。
- **记忆色**：
  - **印泥朱砂**：白昼 `#B52315`（`6.4:1`）/ 夜间 `#FF806E`（`7.3:1`）；
  - **泥金古铜**：白昼 `#734B00`（`6.7:1`）/ 夜间 `#F0C05A`（`10.5:1`）；
  - **石绿（稳定印记）**：白昼 `#0F5E3E`（`7.4:1`）/ 夜间 `#5EE0A0`（`10.9:1`）。

### 3. 字体方案（可自托管开源字体）
- **竖排大标题与题干精排**：生产自托管推荐 `Source Han Serif SC / 思源宋体 Bold`（SIL OFL 1.1，样张实配 `STZhongsong / 华文中宋`），刀刻感极强。
- **朱笔眉批与批注标题**：生产自托管推荐 `LXGW WenKai / 霞鹜文楷 Bold`（SIL OFL 1.1，样张实配 `STKaiti / 华文楷体`），形成“正文铅印宋体 + 旁批手书楷体”的真实批注层次。
- **巨型斜体卷标数字**：生产自托管推荐 `Fraunces` 或 `Newsreader Italic`（SIL OFL 1.1，样张实配 `Bodoni MT / Georgia Italic`）。

### 4. 核心互动清单
1. **七日朱砂方印（Hanko Roll）**：点击任一日期格盖下微倾 `-6°` 的 `〔习〕` 朱印（开启声效时伴随木章落纸顿音）。
2. **虚线骑缝撕票任务签（Perforated Tickets）**：点击或按 `Space` 撕下当前任务签，左侧大号斜体票根变绿、右侧加盖微斜红印 `〔已毕〕`，上方 `112px` 剩余计数实时递减。
3. **四册立式藏书脊（Vertical Book Spines）**：四科化作四本竖排立在书架上的典籍（`卷壹·数据结构` 至 `卷肆·计算机网络`），书脊上镶嵌 `○ / ◐ / ◕ / ●` 墨珠，点按即可研墨升阶。
4. **全景 0～399 磁道算盘标尺 + 朱笔楷书眉批（2024 Q32 CSCAN 真题）**：无外框双栏古籍批注版式，点击 `A/B/C/D` 实时重绘上方 1160px 宽磁道折返线，朱砂虚线醒目切出 `0⇢399` 循环回跳。
5. **100vw 满幅乌金河图长卷**：打破白底节奏，以黑漆金线长卷串联操作系统先修源流与 `45/46` 综合大题去向。

- **路径**：`output/design-directions-2026-11-25/editorial-almanac/index.html`（同目录附昼夜 1440/390 四张截图）

## 方向三：琥珀示波台 · `phosphor-oscilloscope`（主推荐候选 · 硬核仪器玩具感）

### 1. 一句话概念
向 **Braun / Teenage Engineering 暖灰工业硬件** 与 **Tektronix P3 琥珀荧光示波器** 致敬：**即使在白昼模式下，机身顶部与核心总线依然是一块内嵌的深黑高反差琥珀荧光屏**，搭配可点击旋转的物理波段旋钮、按压下沉 `2px` 的厚底机械键与跨屏滑动的微秒游标卡尺。

### 2. 色板（白昼：暖灰铝壳内嵌黑晶屏 / 夜间：全暗室琥珀荧光屏）
- **硬件机壳**：白昼暖灰阳极铝 `#DDD7CC` / `#EAE5DC`（正文石墨黑 `#141210`，对比度 `14.2:1`）；夜间全黑机壳 `#090806` / `#13110D`（正文暖米白 `#F7EBD2`，对比度 `15.8:1`）。
- **内嵌常暗 CRT 视窗**（昼夜保持高辨识度深底 `#11100C` / `#070604`）：
  - **P3 琥珀荧光主色**：`#FFB82E` / `#FFC23D`（对比度 `10.8:1`）；
  - **P31 磷光薄荷绿**：`#3DF094`（对比度 `12.4:1`）；
  - **镉橙触发实体键**：白昼 `#B8330A`（配白字 `5.9:1`）/ 夜间 `#FF8552`（配深墨 `8.1:1`）。

### 3. 字体方案（可自托管开源字体）
- **巨型数码读数与面板丝印**：生产自托管推荐 `Chakra Petch` 或 `Space Grotesk`（SIL OFL 1.1，样张实配 `Bahnschrift Condensed` `86px` 数码读数 `03:11`）。
- **哑光视窗题干阅读**：`Source Han Sans SC Regular`（SIL OFL 1.1），题干放在哑光面板而非发光网格上，无任何发光模糊，长文阅读稳健。
- **示波刻度与寄存器**：`Cascadia Mono` / `JetBrains Mono`（SIL OFL 1.1）。

### 4. 核心互动清单
1. **100vw 顶部全景琥珀示波屏**：按 `Space` 或点按琥珀触发键 `⚡ TRIG +1`，方波高电平前沿与发光采样点实时向右推进，左侧 `86px` 数码管跳字。
2. **可点击旋转的机械波段旋钮（`CHANNEL SELECTOR`）**：每次点击旋钮指针带弹簧过冲旋转 `40°`（开启合成音时发出清脆档位咔哒声），依次单声道监听 `CH1·DS → CH2·CO → CH3·OS → CH4·CN` 四条逻辑电平排。
3. **1220px 跨屏微秒游标卡尺（2024 Q36 802.11 CSMA/CA NAV 真题）**：下方四个厚底硬件实体按键对应 `A/B/C/D`，按下时上方琥珀 CRT 屏幕里的两条虚线游标卡尺立刻卡住对应时间段，直观暴露 `A(326μs)` 漏计首个 `SIFS(28μs)`。
4. **四拍 SR 选择重传双总线飞行镜（2024 Q37 真题）**：点按 `01～04` 档位复现 `F1` 丢包、`t1` 滑窗发 `F4`、`t2` 超时单帧重传 `F1`。

- **路径**：`output/design-directions-2026-11-25/phosphor-oscilloscope/index.html`（同目录附昼夜 1440/390 四张截图）

## 推荐建议与产品落地工作量

### 我最推荐哪个？
如果目标是 **彻底洗掉“老套模板感”、让人打开第一秒就眼前一亮且每天都想点两下**：

1. **首选推荐：方向三「琥珀示波台 `phosphor-oscilloscope`」或 方向二「朱墨算经 `editorial-almanac`」二选一（取决于维护者的审美偏好是“硬核精密仪器玩具”还是“沉静东方纸本典籍”）**：
   - **选方向三（琥珀示波台）的理由**：BitAtlas 拥有全网罕见的 **34 个硬核计算机可视化实验**（CPU 流水线、Cache/TLB、滑动窗口、CSMA/CA、磁盘寻道）。“暖灰机身 + 内嵌琥珀荧光 CRT + 旋钮与游标卡尺”把整个网站统一成一台专属于维护者自己的 **408 桌面逻辑分析仪**，同时把长题干隔离在无眩光的哑光面板里，既酷又真正服务做题与实验。
   - **选方向二（朱墨算经）的理由**：如果维护者每天刷题 3～5 小时、希望界面完全不像电子后台而像一本考究的精装工具书，竖排中宋标题 + 骑缝撕票签 + 四卷立式书脊 + 乌金河图长卷具有极高的人文耐看度与东方设计辨识度。
   - **方向一（深紫外硅晶光刻 v2）** 则适合喜欢锐利几何切角与圆形晶圆全局视野的折中路线（其中 **圆形 102 核硅晶圆图** 无论最终选哪套主题，都可以作为知识页或今日页的招牌组件保留！）。
