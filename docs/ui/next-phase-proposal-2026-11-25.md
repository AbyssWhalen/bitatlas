# BitAtlas 下一阶段学习体验走查与改进方案

2026-11-25 · 基于本地模式与服务器模式真实 Chrome 五段学习者旅程走查（证据与静态样张目录：`output/playwright/opus-ui-2026-11-22/next-phase-review/`）。本方案严格遵守既有合同：概念状态只用四态与真实计数（不输出掌握度百分比）、AI 辅助内容不标“已审核”、不伪造未经授权的计时组卷、不锁死基础统计报告。

## 总体判断

上一轮改版解决了“全站看起来像不像同一个产品”，而以 408 备考者身份完整走完新成员首登、日常计划、答错复盘、考前冲刺、手机十分钟五段旅程后，当前最大的矛盾是**“资产在库里，不在手边”**。BitAtlas 底层已经把 799 道真题 100% 映射到 102 个跨年叶概念，配齐了 80 张记忆卡、20 篇原创短讲解和 34 个可复算实验，首答证据与按日最低评分调度也很扎实；但**做题、看讲解、背卡片、跑实验四个环节在界面上仍是分开的四座岛**。最需要串联的“答错那一刻”反而断了链：判错并标下“错因：概念”后，练习页既不显示本题考哪个概念，也打不开现成的短讲解、关联卡片和跨年实验（实测全库有 **479 道题**的概念已有实验，目前练习页只给 2009 年的 35 道题开了入口）；跳去实验室又回不到原练习轮次；平时认真标的错因到了错题本里既看不见也不能筛。下一阶段不必做装饰性新功能，最值得做的是**在“判错当下、每日收尾、考前筛查、手机单手”四个节点把现成资产接通成闭环**。

## 按优先级排序的 6 项改进方案

### P1 · 打通“判错当下”的学习闭环：练习页原地接入概念、短讲解、卡片与跨年实验，实验页补“返回原练习”条

- **现状**：
  - 练习页提交判错并点选错因（如“概念”）后，只显示文字解析；2024/2025 的 80 道单选显示“本题文字解析缺失，请通过‘来源页’查看原始答案资料”。页面全程不显示本题所属叶概念、短讲解或关联记忆卡（`j3-wrong-q1-no-lab-no-concept-1440.png`、`j3-2024-missing-exp-no-lab-1440.png`）。
  - 右侧“可视化实验”只调 `questionLabLink(question.id)` 匹配硬编码的 35 道 2009 真题。实测 `learning.json` 中全库共有 **479 / 799 题（60%）**映射的叶概念已有实验、**341 题**有短讲解、**678 题**有记忆卡——例如 `2024 Q12`（`short/int` 截断与符号扩展）所属概念“整数编码、扩展与溢出”明明已有补码实验和短讲解，但在 `2024 Q12` 缺解析时右侧一片空白（`j3-2024-missing-exp-no-lab-1440.png`）。
  - 即使在 2009 的 35 道题上点实验跳走，实验页右上角只有“相关真题 N 题”或“练习 2009 · QXX”（点击会新建独立会话），没有回到刚才做到一半的练习轮次的入口（`j3-after-jumping-to-cache-lab-1440.png`）。
- **问题**：做错后的 30 秒是纠正概念偏差黄金期。现在学习者要么被迫中断整轮练习自己去“知识/实验”里翻找，要么直接点“下一题”滑过去，重资产形同隐身。
- **方案**（静态布局样张见 `mockup-p1-closed-loop.html` 及渲染图 `mockup-p1-closed-loop-1440.png`）：
  1. **练习页提交后在 `.rl-answer-panel` 底部挂载“关联概念与巩固”卡**（主阅读栏内，桌面与手机同流，不塞进手机底端 1700px 外的侧栏）：展示本题叶概念名、四态图标与 `已练 m/n 题 · 记忆卡 k 张`；若该概念有 `ConceptArticle`，提供 `<details>` **原地展开短讲解**（保留“AI 辅助原创讲解 · 待审核”说明，不必离开当前会话）；提供 **去概念实验验证**（优先用 `questionLabLink(question.id)` 真题预设，无则回退到概念级 `ConceptStateRow.labIds[0]` 或 `article.labPath`，将实验入口从 35 题扩至 479 题）、**关联记忆卡（k 张）** 入口。
  2. **缺解析题的一键看原卷**：当 `availability.explanationMissing` 为真时，在提示语旁直接放一颗内联“查看原卷与答案扫描页 →”按钮打开现有 `sourceModal`，省去跨栏寻找。
  3. **实验页返回上下文条**：从练习页跳实验时附带 `?fromSession=<sessionId>`；`LabExhibit` 校验该会话仍存在且未关闭时，在展厅顶栏醒目展示 `← 返回刚才的练习（第 X / N 题）`，避免误点“练习 QXX”另起炉灶。
- **对学习的作用**：把“答错 → 记错因 → 看概念易错点 → 去实验推演一步 → 无损回原轮次继续”压成不断裂的一条线，直接激活 2010–2025 真题上的实验与讲义复用。
- **工作量**：中（约 1–1.5 天；涉及 `PracticePage.tsx`、`LabExhibit.tsx`、`lab-links.ts` 只读辅助与 `reading-layer.css`）。
- **依赖**：完全复用现有 `useLearning()`（`pack.mappings`、`pack.articles`）、`useConceptRegister()`（`concepts[].labIds`、`state`、`cardCount`）与 `useStudy().getSession`，零后端/存储改动。

### P2 · 修复图片选项点击误弹整页灯箱，收敛练习页与总结页的双份错因笔记

- **现状**：
  - 遇到选项含裁剪图的真题（如 `2009 Q4` 平衡二叉树，A–D 四个选项均为树图），学习者点击选项内的图形准备选答案时，事件冒泡触发 `.rl-reading-col` 的 `handleImageClickDelegation`，瞬间弹出**整张未裁剪原卷第 1 页大图灯箱**遮死“提交答案”按钮（`j2-q4-image-option-hijacks-lightbox-1440.png`）；同样委托逻辑也存在于 `MockExamSessionPage`。
  - 练习页侧栏的“笔记”（写入 `questionNotes`）与本轮总结页的“补充笔记”（写入 `PracticeEvidence.mistakeNote`）彼此孤立；且 `PracticeSummaryPage` 对**本轮答对的题**也逐题展开一整套“错因下拉 + 补充笔记 + 保存错因”空表单（`j2-practice-summary-after-daily-8q-1440.png` 第 2 题）。
- **问题**：408 树、图、电路、时序图选项极多，点选项却弹整张试卷严重打断做题（模考倒计时下尤甚）；两处笔记不互通、总结页满屏空表则稀释了真正的错题复盘。
- **方案**：
  1. **选项防误触与局部放大**：在 `PracticePage` 与 `MockExamSessionPage` 中，未提交态点击 `button.rl-option` 一律只执行选答案，不触发灯箱；若需放大选项图，在选项右上角提供独立小放大镜按钮（或提交后点图），且对 `.source-inline-crop` 优先按裁剪视口放大局部图形（灯箱顶栏附“查看整页原卷”切换）。
  2. **错因笔记同源与总结页折叠**：在练习页 `PracticeMistakePanel` 点选错因枚举后，下方顺手提供单行可选 `mistakeNote` 输入（读写同一条 `PracticeEvidence`，见 `mockup-p1-closed-loop-1440.png`）；`PracticeSummaryPage` 默认只展开**答错题、未满分综合题或已填错因的题**，客观答对题收拢为带题干首句摘要的单行卡片（可手动点开补充）。
- **对学习的作用**：保障图形题作答零惊吓，记一次错因摘要在练习页、总结页和错题本处处可见，总结页一眼锁定失分点。
- **工作量**：小–中（约 0.5–1 天；涉及 `PracticePage.tsx`、`MockExamSessionPage.tsx`、`PracticeMistakePanel.tsx`、`PracticeSummaryPage.tsx`）。
- **依赖**：复用现有 `storage.reviewRepository.savePracticeEvidence`、`ReadingImageLightbox`，不改 schema。

### P3 · 错题本升级为“考前诊断台”：补齐科目与错因筛选，在题目行透出历史错因与笔记

- **现状**：学习者在练习中逐题标了错因（概念 / 方法 / 计算 / 审题 / 其他）和笔记，但打开 `/wrong`（错题重练）时，筛选栏**只有“错题年份”一个下拉框**，既不能按四科筛选，也不能按错因筛选；每行只显示“当前题面错误 N 次 · 学习中”，完全看不到之前记下的错因或易错点笔记（`j4-wrong-page-filters-1440.png`）。
- **问题**：考前冲刺从来不是“今天重做 2013 年的错题”，而是“上午把计网错题清一遍”或“考前两天专门把标过‘计算失误 / 审题失误’的题过一遍防低级丢分”。只让用户记错因却不在错题本里用起来，记错因就会沦为无反馈负担。
- **方案**：
  1. **补齐双维筛选**：在 `WrongPage` 顶部加入四科分段切换（`全部 / ▲ 数据结构 / ■ 组成原理 / ● 操作系统 / ◆ 计算机网络`）与错因胶囊过滤（`全部 / 概念 / 方法 / 计算 / 审题 / 其他 / 未标错因`），主按钮动态显示 `开始重练 N 题`。
  2. **行内展示诊断记录**：在每道错题元数据行展示最近一次当前题面版本的错因标签（如 `[错因：概念]`），若有 `mistakeNote` 或个人 `note` 则在题干下方灰底单行摘录（可点开完整查看）。
- **对学习的作用**：打通“平时标错因 → 考前按科目/失分类型靶向清零”的正反馈闭环。
- **工作量**：小（约 0.5 天；仅改 `WrongPage.tsx` 与 `secondary.css`）。
- **依赖**：`useLearning().evidence` 与 `useStudy().notes` 已在前端内存中，纯只读派生。

### P4 · 串起“今日学习”首尾动线：消除新成员首屏双按钮分叉、打通题卡接力、清除卡片总结裸 ID

- **现状**：
  1. **新成员首屏分叉**：新受邀成员首次注册进入今日页（`0 / 11`，`已练 0 / 799`），页头摆着“继续学习”（390 手机首屏甚至排在“开始剩余 8 题”正上方，见 `j1-new-member-today-1440.png`、`j1-new-member-today-390-fold.png`）。点“继续学习”在无历史会话时会调用 `availableQuestions.slice(0, 8)` 创建一个**不带 `dailyPlanId`、固定抓 2009 前 8 题**的游离会话，与今日计划脱钩。
  2. **做完今日题目后接不上今日卡片**：完成今日 8 题进入 `PracticeSummaryPage` 后，“接下来”只有“重练本轮错题”和跳往公共卡库列表的 `/review#cards`（`j2-practice-summary-after-daily-8q-1440.png`），没有“继续今日剩余 3 张记忆卡”按钮；若 8 题全对，唯一主按钮 `重练本轮错题（0）` 直接灰死。
  3. **卡片总结裸露数据库 ID & 今日完成态无回响**：刷完 3 张今日卡后，`CardReviewPage` 总结列表直接显示 `card-cn-01 / card-cn-02 / card-cn-03`（`j2-card-round-summary-raw-id-1440.png`）；回到今日页 `11 / 11` 完成后，只剩两颗灰掉的 `开始剩余 0 题`、`复习 0 张卡片`（`j2-today-all-11-done-1440.png`），既不提示复盘刚才做错的 7 题，也没交代“为何全做完后‘稳定’概念还是 0（稳定需跨日复习间隔 ≥ 3 天）”。
- **方案**：
  1. **今日页首屏收口**：仅当存在未完结的**非今日计划**练习会话或卡片轮次时，才展示“继续上次未完练习（第 X/Y 题）”；首次进入或无游离会话时隐藏该按钮，让“开始剩余 8 题”成为唯一明确起点，并为 `practiced === 0` 的新成员附一句温和指引（“今日清单按到期优先自动固定；想按科目或近年真题自选可随时去题库”）。
  2. **总结页题卡接力与完成态收尾**：若当前练习绑定 `dailyPlanId` 且今日计划尚有未完成卡片，`PracticeSummaryPage`“接下来”直接提供 `继续今日剩余 N 张记忆卡 →`（一键拉起今日卡片轮次）；今日页 `11 / 11` 全部完成后，将两颗禁用按钮替换为完成提示条（有当日错题时给“复盘待处理错题（N）”，无错题时说明“今日计划已完成 · 稳定状态将在跨日间隔 ≥ 3 天后点亮”）。
  3. **替换裸卡片 ID**：`CardReviewPage` 总结页复用 `ReviewPage` 的“概念名 · 正面摘要”格式化函数替代 `{item.id}`。
- **对学习的作用**：消除首日迷茫与游离会话陷阱，把每日“8 题 → 3 卡 → 当日收尾”串成一条顺滑管道。
- **工作量**：小–中（约 0.5–1 天；涉及 `DashboardPage.tsx`、`DailyTasks.tsx`、`PracticeSummaryPage.tsx`、`CardReviewPage.tsx`）。
- **依赖**：复用 `useLearning()`（`plan`、`rounds`、`contexts`、`pack.concepts`）与 `useStudy().getLatestSession`。

### P5 · 手机端（390px）单手十分钟减负：收起 98.9% 题目的死提示按钮、阅读栏内联轻工具条

- **现状**：
  - 全库 799 题中有 **790 题（98.9%）没有提示**，但 `PracticePage` 在每道题的“提交答案”左侧都并排占去一半宽度显示禁用按钮 `💡 暂无可用提示`（`j5-mobile-practice-unsubmitted-390.png`）。
  - 390×844 实测：未滚屏时选项 D 底边（`y=778px`）紧贴底部静态五栏 `.mobile-nav`（`y=782px`，仅差 4px，`j5-mobile-practice-submitted-fold-390.png`）；提交后若想点“原卷第 X 页 / 笔记 / 掌握度”，必须滑过整段解析和翻页栏，一直滚到内部容器 `y=1704..2281px`（两屏半以下）才能碰到 `.rl-tools`。
- **问题**：碎片时间单手握持手机时，主提交键被无意义的禁用按钮挤小一半，看一眼原卷扫描图或随手记一句笔记需要上下长途往返滚屏。
- **方案**（注意：`tests/e2e/visual.spec.ts:152` 明确断言练习页 390 视口保留静态 `.mobile-nav` 分区，因此**不隐藏 `.mobile-nav`**，零破坏测试契约）：
  1. **按需渲染提示键**：`question.hints.length === 0` 时不渲染提示按钮，让 `提交答案 →` 在手机上占满整行宽度（有提示的 9 道题正常显示 `提示 0/N`），同时给 `.rl-workspace` 底部留足内边距拉开与底栏的安全间距。
  2. **手机端题头轻工具入口**：在 `≤ 760px` 下，于题头收藏按钮旁并排放置紧凑芯片 `原卷` 与 `笔记`（点“原卷”直接开现有扫描弹窗，点“笔记”原地展开轻量输入框或平滑定位），不必滚到 2000px 底部。
- **对学习的作用**：释放手机拇指热区宽度，单手刷题、看原卷、记笔记都在一屏之内完成。
- **工作量**：小（约 0.5 天；改 `PracticePage.tsx` 与 `reading-layer.css`）。
- **依赖**：纯前端条件渲染与响应式样式，完全兼容现有 `visual.spec.ts` 布局断言。

### P6 · 考前冲刺口径与出口对齐：统计页统一四态、专项练习定量抽题、未开放模考页补整年练习出口

- **现状**：
  1. **统计页仍出百分比、知识页卡片数前后不一**：`StatsPage`“薄弱知识点”仍调旧 `aggregateKnowledgePerformance` 显示 `0% 当前表现`、“低于 80%”（`j4-stats-after-study-1440.png`），与定稿“概念状态不输出百分比”冲突；`KnowledgePage` 右侧详情上方写 `记忆卡 2 张`，下方却因 `card.sources` 宽泛匹配写出 `相关记忆卡（6）`，点进复习页又变回 2 张（`j4-knowledge-desktop-1440.png`）。
  2. **寄存器缺状态过滤，专项练习一锅端**：102 格寄存器不支持筛选“只看练习中 / 待巩固”；点“专项练习”会把该概念全部 21–31 道跨年题按 2009→2025 一次性塞进会话（刚做过的 2009 题又排第一）。
  3. **服务器普通成员进模考页零出口**：2009 题包未完成人工复核前，普通成员打开 `/mock` 全页**没有任何按钮或链接**（`j4-server-member-mock-closed-1440.png`）。
- **方案**：
  1. **统一四态与卡片计数**：`StatsPage` 薄弱知识点改由 `useConceptRegister()` 驱动，优先列出 `state === 'practicing'` 且 `objectiveByConcept === 'needs-review'`（确有客观错题）的叶概念，展示四态徽标与 `已练 m/n 题`，移除综合百分比；修正 `KnowledgePage` 的 `selectedCards` 使其与 `useConceptRegister` 及 `/review?concept=` 口径严格一致。
  2. **寄存器状态筛选 + 专项定量抽题（落实评审 A6）**：知识页寄存器增加 `全部 / 练习中 / 待巩固 / 未开始` 过滤芯片；从知识页或统计页发起专项练习时，提供轻量范围选择（默认 `错题与未做优先`，可选 `5 题 / 10 题 / 全部`，仍走普通 `createSession`，不冒充计时组卷）。
  3. **模考未开放时的诚实替代路径**：保留 2009 正式计时模考的人工复核门槛不变；在未开放提示框内为所有成员增加 `去题库按年份顺序自测 →` 次按钮（跳转 `/questions?year=2025` 走普通不计时整年练习），消除死胡同。
- **对学习的作用**：消除跨页数字打架，让考前查漏补缺“筛得出薄弱格、每次抽 5–10 题吃得下、想刷整套近年真题有路走”。
- **工作量**：中（约 1 天；涉及 `StatsPage.tsx`、`KnowledgePage.tsx`、`ConceptRegister.tsx`、`MockExamPage.tsx`）。
- **依赖**：复用 `useConceptRegister()`、`currentProgress`、`createSession`，零后端改动。
