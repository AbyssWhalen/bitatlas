## 事故与修复

`git worktree remove` 删除检出目录时，跟随了检出目录 `node_modules/.bin`、`.vite` 两个 junction，把主仓的 `node_modules/.bin` 和 `node_modules/.vite` 清空了。之后它在下一个条目报错停止，其余 433 个包的 junction 及其目标都没有动到。

修复方法是运行 `npm rebuild --ignore-scripts`，离线重建了 102 个命令入口，不运行安装脚本，也不联网下载。`.vite` 是 Vite 的依赖缓存，会自动重建。修复后的验证：
- `npm ls` 无缺失；
- `npm run typecheck` 全部 workspace 通过；
- `vitest run packages/domain` 58/58 通过；
- tsc、vitest、playwright、eslint、vite 都能启动。

**以后删除本项目任何目录前**，先列出其中的 junction 和符号链接：

```powershell
Get-ChildItem -LiteralPath <目录> -Recurse -Force -Attributes ReparsePoint
```

发布时临时做的检出目录，常把 `node_modules` 逐项 junction 到主仓。先逐个只删链接，再删目录：

```powershell
[System.IO.Directory]::Delete($link, $false)
```

不要对含 junction 的目录直接用 `git worktree remove` 或会跟随链接的递归删除。发布临时检出也不要放进 `output/` 后就丢下不管：用完先拆掉 junction。
