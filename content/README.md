# Content metadata

本目录只保存来源元数据、schema 示例和明确允许追踪的内容。公开仓库故意不附带可直接使用的 2009 题包；原始 PDF、结构化真题、来源页图和 OCR 结果保存在 `.gitignore` 覆盖的本地目录。

2009 题包由 `tools/content-importer` 生成。生成成功不代表完成逐题人工复核，`needs-review` 题目不得作为正式公开题库发布。

干净克隆可以在无题包模式启动，实验室与本地工具仍可使用。完整生成、人工复核和公开提交边界见 [`docs/LOCAL_CONTENT.md`](../docs/LOCAL_CONTENT.md)。
